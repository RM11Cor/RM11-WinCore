# القفل الشامل — معاينة تصميم 1.1.0

**المطوّر:** مؤمل سعد  
**المنصة:** Android 9+ مع استهداف Android 16، لكن اختبار POCO F7 وGoogle Play Protect لم يكتمل.

## تصميم الواجهة
- لوحة رئيسية ذات حالة واضحة للحماية، وزرين طريقتي الحماية.
- صفحة التطبيقات بقائمة قابلة للبحث وأزرار «إضافة / إزالة / قفل».
- صفحة الحماية لشرح أذونات بيانات الاستخدام والظهور فوق التطبيقات.
- صفحة الإعدادات للتحقق البيومتري ورمز الحماية ورمز الاستعادة.
- صفحة المزيد، ومركز المساعدة، ومعلومات المطور، وشاشة التشخيص.
- رموز عربية واضحة ورموز المنصات الأربع وروابطها، مع درجات اللون الأزرق والبنفسجي والواجهة البيضاء الهادئة.
- تحسين حالة شريط النظام والأزرار داخل Android 15 / 16.

## الأذونات والأمان
- إذن بيانات الاستخدام: لرصد التطبيق الذي يظهر في الواجهة.
- إذن الظهور فوق التطبيقات: لتقديم شاشة رمز الحماية.
- خدمة أمامية بإشعار دائم: تستمر فقط ما دام القفل مطلوباً.
- التحقق بالبصمة / الوجه، عند دعمه من نظام الجهاز.
- لا تتطلب النسخة خدمة إمكانية الوصول، ولا إذن إنترنت أو رسائل أو جهات الاتصال.

## حدود مثبتة
ظهر على الهاتف الفعلي حظر من Google Play Protect ورسالة منع إذن بيانات الاستخدام. لا يمكن للكود أو التصميم إزالة تحذيرات Google، ولا يُنصح بتعطيل Play Protect لتثبيت التطبيق.

بسبب هذه الحالة، **لا تُعد نسخ APK التجريبية معتمدة للتثبيت**؛ البناء ينتج مرفقات اختبار داخل GitHub Actions فقط، دون النشر العام التلقائي. يلزم تدقيق الكود، إقرار الصلاحيات، والتقديم إلى Google Play / استئناف تصنيف Play Protect قبل الإصدار الرسمي.

## فحوص المشروع
- تجميع Android وKotlin.
- فحص توقيع APK وصلاحياته في GitHub Actions.
- اختبار فتح الواجهة على محاكي Android 15 (ليس اختباراً لـ Play Protect ولا جهاز POCO الفعلي).
