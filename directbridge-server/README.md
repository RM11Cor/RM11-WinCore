# RM11 DirectBridge Server (MVP)

This Vercel Node server exposes:
- GET /health: public service status; **not** evidence of device pairing.
- POST /ingest: device-initiated HTTPS upload of a bounded AES-256-GCM encrypted diagnostic with per-install random 256-bit code.
- POST /mcp: read-only Streamable HTTP MCP tool get_rm11_diagnostic. Its argument must contain the complete 256-bit access code; there are no listing or arbitrary-shell tools.

Requires a **private** Vercel Blob store connected to the project. Never create a public Blob store for diagnostic reports. The server does not store the access code or decrypted report, and the key is generated by the mobile application and stays in its private preferences until deliberately shared for pairing.

Security limits: the ingest endpoint is not yet quota/rate-limited; this is a single-device personal MVP and should be protected against abusive clients at the edge before enabling broad public traffic. Do not put passwords, user names or arbitrary game save files into diagnostic payloads. Each report is bounded; upload only after user enables pairing. Do not claim this bridge can run commands.

This backend must be actually deployed and connected through a supported ChatGPT MCP plugin to permit ChatGPT to read the report. Publishing a server or APK alone does not establish that connection.

**Account scope:** project owner RM11Cor. `directbridge-server` deploys separately from the Android application; it does not change Wine/FEX runtime.
